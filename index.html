Off-grid packet radio & embedded devices

LoRa mesh, authenticated alerts & field hardware

I build an open-source, end-to-end LoRa & MeshCore stack — from the 87-byte signed wire protocol verifiable offline on a microcontroller, to the handheld touchscreen UI and Linux desktop console, to the USB/SDR observer bridge:

Sign & Verify · C99 · Python 3.14 · TypeScript · v1.0-rc

sigillo

Compact signed frame for public alerts over low-bandwidth packet radio. Packs a 7-byte header, the 16-byte EU Common Alert Message Format (Galileo CAMF Issue 1.2) block, optional TLV extensions, and a 64-byte Ed25519 signature into an 87-byte base frame (well inside MeshCore's 165 B group limit). Includes a CC BY 4.0 specification, locked conformance vectors (vectors/v1.json), and three bit-exact reference libraries: sigillo-c (C99, gcc/clang ASan & UBSan), sigillo-py, and sigillo-ts.

  • 87 B base frame (7 B header + 16 B CAMF + 64 B Ed25519)
  • Offline verification & strict Ed25519 rules
  • Clockless node support (VALID_AGE_UNKNOWN + TIME beacons)
  • Primary & backup roots · KEY / REVOKE / ROTATE
