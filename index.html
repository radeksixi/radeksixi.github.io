Off-grid LoRa mesh & authenticated alerts

A complete open-source stack for packet-radio communications when power and mobile networks go down — from the 87-byte signed wire frame to the handheld UI, desktop console, and SDR telemetry bridge:

  • sigillo: compact 87-byte Ed25519-signed public alert frame (EU Galileo CAMF block, offline verification, conformance test vectors, and reference libraries in C99, Python and TypeScript)
  • sixi-tdeck-plus (Faro): clean-room LVGL 9 touch-first handheld UI and Linux desktop companion console for MeshCore on LilyGo T-Deck Plus, T-Beam S3 Supreme and Heltec V3 (2D mesh graph, SX1262 link-budget calculator, offline SNR heatmap, 1-click WebSerial flasher)
  • sixi-observer: LoRa & RTL-SDR V4 observer bridge with local Ed25519 advertisement verification, ML Bayesian ghost-hop repeater triangulation, and a 0 ms local WebSocket stream
