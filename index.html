sixi-asi · Native C++20 / CUDA inference runtime

Hybrid MoE & Gated DeltaNet inference engine

Modern open-weight models mix full attention with linear attention (Gated DeltaNet) whose state cannot be truncated like a KV cache, which makes speculative decoding hard. sixi-asi is a C++20 speculative-decoding server for these models on NVIDIA Jetson Thor and DGX Spark unified-memory hardware, with llama.cpp as the compute backend and zero Python in the runtime path. Public fork of my private research branch, version 0.9:

Inference Engine · C++20 · CUDA · OpenAI HTTP/SSE

sixi-asi

Speculative decoding for hybrid Gated-DeltaNet + attention models with O(1) recurrent-state rollback, lossless for greedy and sampled decoding, block drafters (DSpine, DSpark, DFlash2), a Thor-specific llama.cpp kernel patch, a prefix cache with tail checkpoints for long documents, and a native Qwen3.8 chat template that renders byte-identically to llama.cpp's Jinja. Measured on an NVIDIA Jetson AGX Thor with identical prompts for every engine: 45.3 tok/s vs llama-server 43.7, NVIDIA TensorRT Edge-LLM 45.4 (NVFP4) and plain AR 11.9 on Qwen3.8-27B; 65.7 tok/s on a reasoning workload at 28/30 GSM8K and 19/20 HumanEval; follow-up question on a 63k-token document in 1.0 s instead of 209 s.

  • 3.8× over autoregressive · lossless (TVD-tested)
  • Thor kernel patch: 8-row verify 163 → 88 ms
  • 63k-token document: next question in 1 s
  • Drop-in OpenAI HTTP/SSE server · 0 Python

Sixi · Measured security for AI agents

Attack, judge with code, prove on the wire, gate in CI

Most AI red-teaming tools tell you what they think broke. On a real agent, 70–97% of those flags were false alarms. Sixi is the open-source suite I build to close that gap:

Attack & Ship · Go · v0.8.4

sixi-scanner

CLI red-team scanner for LLM agents: 27 single- and multi-turn techniques, one static Go binary, zero dependencies, no LLM inside by default. 1st on precision (0.821) and recall (0.571) on the stateless benchmark, and 1.000 precision (22/22) on multi-turn sessions. Reports as JSON, SARIF 2.1.0, or Markdown. On main: a scan that could not test everything says so, with exit code 3 and a "not tested" list in every format (write-up).

Prove · Benchmark · Python

agent-redteam-benchmark

Seven red-teaming tools (garak, promptfoo, DeepTeam, PyRIT, Azure AI Red Teaming Agent, agent-probe, sixi-scanner) vs one real Microsoft Foundry agent, scored from the wire by 10 deterministic oracles and a tool-blind judge.

Judge · Local LLM & Oracles · Python

laya-as-judge

Local LLM-as-a-judge returning typed verdicts in milliseconds: deterministic oracles evaluate business rules first, calling a model only when code cannot decide.

Sign & Verify · C99 · Python · TypeScript · v1.0-rc

sigillo

Compact signed alert format for low-bandwidth packet radio. Fits an EU public emergency alert and cryptographic signature into a single 87-byte radio packet that any microcontroller or handheld radio can verify 100% offline.
